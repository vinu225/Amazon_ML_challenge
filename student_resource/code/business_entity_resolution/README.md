# Business Entity Resolution Pipeline

This package provides a complete, reproducible pipeline to generate:
- `output/candidate_pairs.tsv`: Final candidate pairs generated by country-partitioned TF-IDF blocking.
- `output/matching_results.tsv`: Highest-scoring business entity matches scored by our LightGBM model.

## Setup

```bash
pip install -r requirements.txt
```

## Running Inference on Test Data

To generate predictions for `dataset/test/`:

```bash
python src/run_inference.py --data-dir ../../dataset/test --output-dir ../../output
```

## Validating Submission Files

To check formatting and schema compliance:

```bash
python ../../utils/validate_submission.py \
    --matching ../../output/matching_results.tsv \
    --candidate ../../output/candidate_pairs.tsv \
    --test-dir ../../dataset/test
```
